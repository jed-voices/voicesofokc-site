# Standard guest communications

Approved process, November 20, 2026: no guest questionnaire or written preparation requirement. Keep media consent before recording; guests may complete it in advance or with the team on arrival. Do not ask for duplicate submissions.

The invitation and reminder use the three optional reply questions agreed with Jed. Personalize bracketed placeholders before sending. Keep the existing branded dual-role signature and the scheduling and consent destinations.

Calendly's podcast event description is the shared source inserted into booking confirmations, basic reminders, and the custom Gmail reminder through its Event Description variable. Keep that description aligned with this policy. Do not replace Calendly's date, time, location, or guest variables with literal sample data.

Form confirmations should acknowledge the specific submission and describe only verified next steps. Tally's native customization may support fewer layout features than these HTML masters.
